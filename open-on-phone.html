Install Abulkour on Android

Scan with your phone's camera, then tap Download.

http://192.168.1.96:4000/download
Steps
  1. Phone on the same Wi-Fi as this PC.
  2. Scan the code (or type the address into Chrome) and tap Download the app.
  3. Open the file and allow installs from Chrome when asked.
  4. If Play Protect warns about an unknown app, tap More details, Install anyway.

If the page doesn't load on the phone, Windows Firewall may be blocking Node.js on private networks.
