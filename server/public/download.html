Abulkour for Android

Live market data, news and AI analysis, from your own server.

Download the app (.apk)
  1. Tap Download. If Chrome warns about the file type, tap Download anyway.
  2. Open the downloaded file. Android will ask to allow installs from Chrome: tap Settings, switch on Allow from this source, then go back.
  3. Tap Install. If Play Protect warns about an unknown developer, tap More details → Install anyway (it's your own app).
  4. Open Abulkour, go to Alerts → Server address, paste your access code and tap Save & test (first time only).

The app connects to the Abulkour server over the internet (Wi-Fi or mobile data). If the server has been idle it takes about a minute to wake up the first time you open the app.
